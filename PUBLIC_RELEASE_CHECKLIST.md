# Public release checklist

The package is ready for the first public GitHub release.

## Licensing — completed

- Python verifier: MIT License.
- Documentation, metadata, manifests, checksums, and archived JSON outputs: CC BY 4.0.
- Scope is documented in `LICENSE.md`.

## Release and archival

1. Create the public GitHub repository from this package.
2. Create the first release as `v1.0.0`.
3. Let Zenodo archive that release and assign its DOI.
4. After Zenodo assigns the DOI, cite that DOI in the IJPE Data Availability Statement and submission metadata.
5. Do **not** create another release merely to write the newly assigned DOI back into the archived files.
